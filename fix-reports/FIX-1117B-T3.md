## 3. 修法（一条规则的两个面）

### 3.1 调用组是**一个结构单元**（修 B5）

`looksLikeNaturalLanguage` 的词数扫描里，遇到 `name` + **配平的** `( … )`
（允许 `(` 前有空白；内部参数、逗号、嵌套调用一并吞掉）就整段跳过：

```kotlin
val groupEnd = callGroupEnd(content, j)
if (groupEnd > 0) { i = groupEnd; continue }
```

- 函数名与参数都不计词、也不产生长词 ⇒ `sin(alpha)+cos(beta)+tan(gamma)` 词数 0。
- **不要求 head 在 `MATH_FUNCTION_TOKENS` 里**：`f(x) = …` 也是公式。名字表管的是
  「长词豁免」，调用组装的是「结构」，两件事分开。
- **不配平就不算调用**（`callGroupEnd` 返回 −1）：流式输入时 `sin(x + 1` 是半截，
  这时 head 继续计词、后面的内容不会被一个永不闭合的组吞掉 —— fail-safe 侧。

### 3.2 散文有独立于词数的信号：功能词（修 B4）

新增 `PROSE_FUNCTION_WORDS`（the/and/or/of/for/per/each/total/with/from/by/as/in/at/is/
than/that/this/if/not），`looksLikeNaturalLanguage` 第一条网：

```kotlin
if (containsProseFunctionWord(content)) return true
```

- **读整段内容，包括调用组内部**：调用组不许把散文藏起来
  （`x + sin(the angle) + 3` 只有组内的 `the` 能救它）。这是任务书 §4 明确的口径。
- 与词数无关：`100 + min(fee) total ` 只有 2 词也判散文。
- 原来的「≥3 词 + 长词」判据**保留**，它是 `velocity + acceleration` 这类命名的安全网。
- `to` **故意不在集合里**：`lim n to inf` 是有文档的公式形状（见 `MATH_FUNCTION_TOKENS` KDoc）。

KDoc 里补了完整来龙去脉：`MATH_FUNCTION_TOKENS` 的「CALL 例外」段改写为「name + 配平组」，
`looksLikeNaturalLanguage` 加了 `[incr1117-B F-11]` 两段（参数仍计词 → 组吞参数；以及放宽后
必须靠功能词网付的那笔账）。

### 3.3 没有动的东西

- `looksLikeMath` 的判定顺序（`$` 残留 → `isCurrencyShaped` → `isCurrencyRangeShaped` →
  散文网 → 字形扫描）**逐字未改**，货币网一行没碰。
- `MarkdownParser` / 流式渲染器一行没碰（单点实现文件，parity 由既有
  `MarkdownMathParityTest` 继续守）。

## 7. 残留 / 取舍（都写进 KDoc 了，不是漏）

1. **`x in A` 从 math 变 text**（差分里唯一一条非报告翻转）。功能词网读整段，`in` 在集合里。
   取舍方向与货币网一致：**漏判公式 = 用户还看得见自己的 `$…$`**；
   误判公式 = `$` 被 KaTeX 静默吃掉。真要写集合隶属应当写 `\in`（含 `\`，在网之前早退不受影响）。
2. **`to` 不在功能词集合**：`lim n to inf` 必须留 math。代价是 `50 to 100 users` 这类句子
   靠词数门（2 词）兜不住 —— 但它首字符是数字、无字形，最终落在货币网/leading-digit 判定 ⇒ 仍是 text。
3. **无 head 的裸括号组不当作调用**（`(alpha beta) + gamma` 判散文）。若要改成「任意括号」，
   必须先有一条真实输入作为依据 —— 现在没有，所以没有做，也没有为它写夹具。
4. **集成层（`collectInlineMathLatex` / `parseWithMath`）本地没跑**：那两个入口拉进 3.5k 行的流式
   渲染器，沙箱编译不了。该层由既有 `MarkdownMathParityTest` / `InlineLatexTest` / 货币测试在 CI
   里覆盖（本支没有改它们的任何被断言面；§6 的 97 条既有字面量已逐条差分，无翻转）。
5. 功能词表是**闭集**，加词等于加新判据面，必须配夹具 —— KDoc 里写明了这条规矩。
