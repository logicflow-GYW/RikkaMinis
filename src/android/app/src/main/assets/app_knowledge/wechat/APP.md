## 页面结构
- 主界面是四个底部标签：微信（会话列表）、通讯录、发现、我。
- 会话列表顶部右上角：放大镜是全局搜索（联系人、聊天记录、公众号、小程序），加号菜单含发起群聊、添加朋友、扫一扫、收付款。
- 通讯录：顶部固定四个入口「新的朋友 / 群聊 / 标签 / 公众号」，下面按字母或拼音首字母排序列出联系人。
- 发现：朋友圈、视频号、直播、扫一扫、看一看、搜一搜、小程序、购物、游戏（部分入口可在「设置 → 通用 → 发现页管理」里关掉，所以别人手机上可能根本看不到）。
- 我：顶部是头像与个人信息卡，下面依次是服务（旧名「支付」）、收藏、朋友圈、卡包、表情、设置。
- 聊天页：顶部是对方/群名，右上角「…」进入聊天信息（群成员、群公告、消息免打扰、查找聊天记录、投诉）。

## 常用入口
- 设置：我 → 设置。里面是账号与安全、朋友权限、通用（字体大小、深色模式、存储空间清理）、隐私、青少年模式。
- 朋友圈：发现 → 朋友圈；发朋友圈点右上角相机图标，长按相机图标可以只发文字。
- 扫一扫 / 收付款：会话列表右上角的加号菜单，或发现页的「扫一扫」。
- 小程序：发现 → 小程序，或在会话列表下拉进入「最近使用的小程序」。
- 深色模式、字体大小、聊天记录迁移与备份都在「设置 → 通用」下面。

## 易混点
- 公众号文章集中在「订阅号消息」这一个会话里，去发现页找不到。
- 「文件传输助手」是自己给自己传文件的会话，不是联系人；「服务通知」是系统推送，不可回复。
- 服务页（原「支付」）里，钱包、银行卡、账单在右上角「钱包」里，与首页的「收付款」不是同一处。
- 长按一条聊天消息会弹引用、转发、提醒、删除；「撤回」只在发出后两分钟内可用，「删除」只删自己这端的记录。
- 群聊的「消息免打扰」在聊天信息里，全局的「新消息通知」在设置里，两处开关互不覆盖。

## 登录与安全页
- 新设备登录一般需要已登录设备扫码/确认，或用短信验证码；同一账号不能同时在两部手机上保持在线。
- 「设置 → 账号与安全」可以查看与管理登录过的设备、设置声音锁、绑定的手机号与应急联系人。
- 冻结/解冻账号、投诉举报、找回密码，入口都在「账号与安全 → 微信安全中心」。
