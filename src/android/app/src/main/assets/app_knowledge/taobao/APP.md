## 页面结构
- 底部标签大致是：首页、购物车、消息（或视频/闲鱼入口）、我的淘宝（改版频繁，以实际屏幕为准）。
- 首页：顶部搜索框 + 拍照搜索图标，下面是签到、频道与推荐卡片区。
- 商品详情页：主图轮播、价格与优惠、规格（SKU）选择，底部是店铺、客服、加入购物车、立即购买。
- 我的淘宝：我的订单（待付款 / 待发货 / 待收货 / 评价）、退款售后、收藏夹、红包卡券、官方客服。
- 订单详情页里才有物流轨迹与「联系卖家」「申请退款」按钮。

## 常用入口
- 搜索与拍照搜索：首页顶部搜索框。
- 订单：我的淘宝 → 我的订单；查物流先进订单详情。
- 购物车：底部第二个标签，可多选合并结算，或进入管理模式批量删除。
- 设置与收货地址：我的淘宝 → 右上角齿轮；收货地址、支付设置、隐私都在里面。
- 官方客服：我的淘宝 → 官方客服（智能助理 + 转人工入口）。

## 易混点
- 天猫店与淘宝个人店混在同一个搜索结果里，商品页带「天猫」标识；售后规则不同。
- 「立即购买」绕开购物车直接下单；最终成交价以结算页为准，详情页价格不含可叠加的优惠。
- 客服分两层：店铺客服在商品页左下角（只能问这家店），平台客服在「我的淘宝 → 官方客服」。
- 「退款」和「退货退款」不同：未发货可选仅退款，已签收一般要走退货退款并填运单号。
- 加入购物车不改库存，下单也不锁库存，付款后才算成交。

## 登录与安全页
- 支持手机号验证码、账号密码、扫码登录；常用设备一般免密直接进。
- 「设置 → 账号与安全」里可以改登录密码、管理登录设备、看实名认证状态、绑定支付宝。
- 支付走绑定的支付宝或花呗，淘宝内不单独存支付密码。
