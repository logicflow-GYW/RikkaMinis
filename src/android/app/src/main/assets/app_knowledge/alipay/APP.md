## 页面结构
- 底部标签通常是：首页、理财、视频、消息、我的（各版本名称与顺序会调整，找不到就点最右边的「我的」）。
- 首页：顶部搜索框 + 扫一扫 / 收付款快捷条，下面是宫格应用中心（生活缴费、市民中心、出行、卡包等）。
- 我的：顶部是头像与账户信息，下面是余额、余额宝、花呗、账单、总资产等卡片，右上角齿轮是设置。
- 转账与收付款是独立页面，进去后顶部标题会明确写「付款码」「收款码」或「转账」。

## 常用入口
- 收付款：首页快捷条或搜索「收付款」；向商家付钱用付款码，让别人付钱给自己用「收款码」。
- 账单：我的 → 账单，可按月与分类筛选，单笔详情里有交易单号与对方信息。
- 设置：我的 → 右上角齿轮。里面是支付设置、隐私、通知、通用、账号与安全。
- 生活缴费、市民中心：首页应用中心，或直接在顶部搜索框搜名称。
- 卡包与出行码：首页「卡包」/「出行」，乘车码在出行页面里。

## 易混点
- 付款码和收款码方向相反：付钱是出示自己的码给商家扫，收钱是展示自己的码让别人扫，看页面标题而不是看二维码。
- 余额和余额宝是两个账户；默认扣款顺序在「设置 → 支付设置 → 扣款顺序」调整。
- 花呗的账单与还款入口在花呗页面里，不在「账单」页里（账单页只汇总流水）。
- 搜索结果里官方服务带「官方」标识，同名的第三方小程序没有，别点错。
- 转账页面的「延时到账」是设置项，选了之后到账时间会变，不代表失败。

## 登录与安全页
- 登录支持密码、指纹、面容；换设备登录通常需要短信验证码或原设备确认。
- 「设置 → 账号与安全」（也可搜「安全中心」）可以改登录密码与支付密码、管理登录设备、开启夜间保护和大额保护。
- 实名认证、绑定手机号、注销账号都在账号与安全里；注销有资产与授权检查，通常不是一步完成。
